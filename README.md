# 노트립 (Note-Trip)

혼자 또는 여럿이 가는 여행의 **일정, 동선, 정산을 앱 하나에서 함께 정리**하고,
여행 중에는 **열자마자 오늘 동선**을 볼 수 있는 여행 플랫폼입니다. PWA로 시작해 이후 Google Play와 App Store 출시를 목표로 합니다.

> 🔗 **배포 주소**: https://travel-platform-sigma.vercel.app/ (폰에서 열고 "홈 화면에 추가"하면 앱처럼 설치됩니다)
>
> 🚧 개발 중: 0단계(프로젝트 세팅) 완료. 진행 상황은 [docs/03-progress.md](docs/03-progress.md)를 참고하세요.

## 왜 만들었나
여행 일정은 공유 문서나 카톡으로, 정산은 또 다른 앱으로 흩어져 관리됩니다.
여행 중 일정을 확인하려면 메모 앱을 열어 메모를 찾아야 합니다.
실제 여행을 준비하던 사용자(여자친구)의 이런 불편에서 출발했습니다.

## 주요 기능 (계획)
- 여행 일정을 동행자와 함께 편집하고 **확정(픽스)**
- 지출 기록과 **최소 송금 횟수 정산**
- 앱을 열면 바로 **오늘 동선과 지도**, 오프라인 열람
- 세계지도에 다녀온 나라 색칠, 성향 기반 나라 추천

## 기술 스택
React · TypeScript · Vite · Tailwind CSS · PWA(vite-plugin-pwa) · Vercel · Supabase(예정) · Leaflet(예정)

각 기술을 고른 이유와 버린 대안은 [docs/02-design.md](docs/02-design.md)에 정리되어 있습니다.

## AI 활용 방식
이 프로젝트는 **Claude Code를 페어 프로그래머로 활용**해 개발합니다. 숨기지 않고 공개하는 이유는, AI와 함께 일하는 방식 자체가 앞으로 개발자의 중요한 역량이라고 생각하기 때문입니다.

**제가 맡는 것**
- **무엇을 왜 만들지 결정하기**: 사용자 요구사항 정리, 기능 우선순위, 범위 조정
- **AI의 답을 검증하기**: 빌드, 린트, 실제 화면으로 직접 확인하고, 이해되지 않는 코드는 반영하지 않기
- **이해하고 설명할 수 있을 때만 다음 단계로 넘어가기**: 배운 개념은 [docs/learning/](docs/learning/)에 제 말로 정리

**AI에게 맡기는 것**
- 코드 초안 작성, 선택지와 장단점 제시, 개념 설명

**AI 작업 규칙** ([CLAUDE.md](CLAUDE.md)에 명시)
- 모든 작업은 이유, 버린 대안과 함께 설명한다
- 한 번에 많이 만들지 않고 작은 단위로 진행한다
- 진행 상황과 결정 근거는 대화가 아니라 저장소(문서, 커밋)에 남긴다

AI가 함께 작성한 커밋에는 `Co-Authored-By: Claude` 표시가 있습니다.

## 실행 방법
```bash
npm install
npm run dev     # 개발 서버 (http://localhost:5173)
npm run build   # 배포용 빌드
npm run lint    # 코드 검사
```
