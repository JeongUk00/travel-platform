# 01. 요구사항 정의서

> 출처: 기획 아이디어를 정리한 문서.

> 요구사항 문서는 "무엇을 만들지"만 다루고, "어떻게 만들지"는 `02-design.md`에서 다룬다.

> 이렇게 나누는 이유: 기술이 바뀌어도(예: PWA → 네이티브 앱) 요구사항은 그대로 유지되기 때문이다.

## 1. 한 줄 정의

**혼자 또는 여럿이 가는 여행의 계획·동선·정산을 앱 하나에서 함께 정리하고, 여행 중에는 열자마자 오늘 동선을 볼 수 있는 여행 플랫폼.**

## 2. 해결하려는 문제

| 지금의 불편함 | 원인 |
|---|---|
| 일정을 공유 문서나 카톡으로 따로 보낸다 | 계획을 함께 편집하고 확정할 공간이 없다 |
| 계획 따로, 정산 따로 정리한다 | 도구가 흩어져 있다 |
| 여행 중 계획을 보려면 폰을 켜고 메모 앱에 들어가 메모를 찾아야 한다 | 급할 때 바로 볼 수 없다 |

## 3. 기능 요구사항

우선순위: **P0** = 첫 출시(MVP)에 꼭 필요, **P1** = MVP 직후, **P2** = 나중에(성공하면)

### A. 여행 일정 계획 및 공유
| ID | 요구사항 | 우선순위 |
|---|---|---|
| A-1 | 여행을 만들 수 있다 (이름, 기간, 목적지) | P0 |
| A-2 | 날짜별로 방문할 장소와 시간, 메모를 추가하고 순서를 바꿀 수 있다 | P0 |
| A-3 | 초대 링크로 동행자를 초대하고 함께 편집할 수 있다 | P0 |
| A-4 | 동행자가 수정하면 다른 사람 화면에도 반영된다 | P1 (처음에는 새로고침으로 해결) |
| A-5 | 일정을 **"확정(픽스)"** 상태로 바꿀 수 있다 (확정 전은 후보, 확정 후는 최종 일정) | P0 |
| A-6 | 혼자 가는 여행도 같은 방식으로 쓸 수 있다 (동행자 0명) | P0 |

### B. 정산
| ID | 요구사항 | 우선순위 |
|---|---|---|
| B-1 | 지출을 기록할 수 있다 (누가 냈는지, 금액, 통화, 항목) | P0 |
| B-2 | 지출을 누구와 나눌지 고를 수 있다 (전원 또는 일부) | P0 |
| B-3 | "누가 누구에게 얼마를 보내면 끝나는지"를 최소 송금 횟수로 보여준다 | P0 |
| B-4 | 해외 통화(엔, 달러 등)를 원화로 환산해 보여준다 | P1 |

### C. 세계지도
| ID | 요구사항 | 우선순위 |
|---|---|---|
| C-1 | 세계지도에서 내가 다녀온 나라를 색칠해 표시할 수 있다 | P1 |
| C-2 | 내 여행 성향(질문 몇 개)에 맞는 나라를 추천받을 수 있다 | P1 (처음에는 규칙 기반) |
| C-3 | 추천을 AI가 해 준다 | P2 |

### D. 여행 중 빠른 확인
| ID | 요구사항 | 우선순위 |
|---|---|---|
| D-1 | 여행 기간 중 앱을 열면 **바로 오늘 동선과 지도**가 보인다 | P0 |
| D-2 | 인터넷이 안 될 때(해외 로밍, 지하철)에도 마지막으로 본 일정은 보인다 | P1 |
| D-3 | 홈 화면 **위젯**에서 오늘 일정을 볼 수 있다 | P2 (스토어 앱 출시 후에만 가능, 설계 문서 참고) |

### E. 확장 기능 (성공하면)
| ID | 요구사항 | 우선순위 |
|---|---|---|
| E-1 | 세계지도에서 나라와 지역별 숙소를 볼 수 있다 | P2 |
| E-2 | 커뮤니티에서 여행 리뷰를 쓰고 공유할 수 있다 | P2 |

### 공통
| ID | 요구사항 | 우선순위 |
|---|---|---|
| Z-1 | 회원가입 및 로그인: **이메일, 카카오, 구글, 네이버** (2026-11-22 기획 결정) | P0 |
| Z-2 | 회원 탈퇴 (App Store 출시 필수 조건) | P0 |
| Z-3 | 개인정보처리방침 페이지 | P0 |

## 4. 비기능 요구사항

| 항목 | 내용 | 이유 |
|---|---|---|
| 모바일 우선 | 폰 화면 기준으로 디자인 | 여행 중에 쓰는 앱 |
| 빠른 첫 화면 | 앱 실행 후 2초 안에 오늘 일정 표시 | "급할 때 바로" 보는 것이 핵심 가치 |
| 오프라인 | 저장된 일정은 인터넷 없이도 열람 | 해외에서 데이터가 불안정함 |
| 비용 0원 | 모든 서비스는 무료 요금제 안에서 시작 | 개발자 예산 없음 |
| 앱 전환 대비 | PWA로 시작하되, 코드 수정을 최소화해 Google Play/App Store로 전환 가능 | 향후 위젯, 스토어 노출 필요 |

## 5. 이번 범위에서 하지 않는 것

- 숙소, 항공 예약 및 결제 (E-1은 정보 표시만 다룸)
- 커뮤니티 (E-2)
- 다국어 지원 (처음에는 한국어만)
