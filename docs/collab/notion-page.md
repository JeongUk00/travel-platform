# ✈️ 노트립 (Note-Trip) 협업 페이지

> 이 페이지는 기획, 디자인, 개발이 같은 그림을 보기 위한 곳이에요.
> 궁금한 점이나 바꾸고 싶은 점은 해당 부분에 **댓글**로 남겨 주세요.

## 한 줄 소개
혼자 또는 여럿이 가는 여행의 **일정, 동선, 정산을 앱 하나에서 함께 정리**하고, 여행 중에는 **열자마자 오늘 동선**을 볼 수 있는 앱.

## 역할
| 역할 | 담당 | 하는 일 |
|---|---|---|
| 기획 | 여자친구 + 정욱 | 어떤 기능이 필요한지, 무엇부터 만들지 결정 |
| 디자인 (UI/UX) | 여자친구 | Figma로 화면 디자인 |
| 개발 | 정욱 | 디자인을 실제 앱으로 구현 |

## 진행 방식
1. 기능 우선순위를 함께 정한다.
2. 디자인을 **먼저** 하고, 그 화면을 개발한다.
   - 개발한 뒤에 디자인이 크게 바뀌면 다시 만들어야 해서 시간이 많이 들어요. 화면 단위로 "이 디자인으로 확정!"을 정하고 넘어가요.
3. 개발된 화면을 폰에서 확인하고 피드백을 준다.

## 기능 목록과 우선순위
**🔴 1순위** = 첫 출시에 꼭 필요 / **🟡 2순위** = 첫 출시 직후 / **⚪ 나중에** = 성공하면

### 여행 일정 계획과 공유
- 🔴 여행 만들기 (이름, 기간, 목적지)
- 🔴 날짜별로 장소, 시간, 메모 추가하고 순서 바꾸기
- 🔴 초대 링크로 동행자 초대해서 같이 편집
- 🔴 일정 **확정(픽스)** 하기 (확정 전은 후보, 확정 후는 최종)
- 🔴 혼자 가는 여행도 똑같이 사용
- 🟡 동행자가 수정하면 내 화면에도 바로 반영

### 정산
- 🔴 지출 기록 (누가 냈는지, 금액, 통화, 항목)
- 🔴 이 지출을 누구와 나눌지 선택
- 🔴 "누가 누구에게 얼마 보내면 끝"을 최소 송금 횟수로 보여주기
- 🟡 해외 통화(엔, 달러 등)를 원화로 환산

### 여행 중 빠른 확인
- 🔴 여행 기간에 앱을 열면 **바로 오늘 동선과 지도**
- 🟡 인터넷이 안 될 때도 마지막으로 본 일정 보기
- ⚪ 홈 화면 **위젯** (아래 "기술적 한계" 참고)

### 세계지도
- 🟡 다녀온 나라 색칠하기
- 🟡 내 여행 성향에 맞는 나라 추천 (처음에는 질문 몇 개로, 나중에 AI)

### 나중에
- ⚪ 나라와 지역별 숙소 정보
- ⚪ 커뮤니티 (리뷰 작성, 공유)

> 💬 **관광 전공자 입장에서 순서가 이상하거나 빠진 기능이 있으면 꼭 알려 주세요!**

## 디자인 요청 순서
개발 순서에 맞춰 이 순서대로 디자인해 주시면 기다리는 시간 없이 진행할 수 있어요.
1. **기본 스타일**: 메인 색상, 글꼴, 앱 아이콘
2. **로그인 화면**
3. **여행 목록 + 여행 만들기 화면**
4. **날짜별 일정 화면 + 지도**
5. **오늘 화면** (앱을 열면 바로 보이는 화면, 가장 중요!)
6. **정산 화면**
7. **세계지도 화면**

## Figma 작업 약속
이것만 지켜 주시면 디자인을 코드로 옮기기가 훨씬 쉽고 정확해져요.

| 약속 | 이유 |
|---|---|
| **폰 화면 크기(폭 390)**로 디자인 | 폰에서 쓰는 앱이라 폰 화면이 기준이에요 |
| **색, 글자 크기를 "변수(Variables)"로 등록** | 개발할 때 그대로 옮겨 쓸 수 있어요. 나중에 메인 색을 바꿀 때도 한 곳만 바꾸면 돼요 |
| **Auto Layout 사용** | 코드의 배치 방식과 거의 같아서 똑같이 구현하기 쉬워요 |
| 글꼴은 **무료 웹폰트** (예: Pretendard) | 유료 폰트는 앱에 쓰려면 비용이 들어요 |
| 버튼, 카드처럼 반복되는 건 **컴포넌트**로 | 개발에서도 같은 단위로 만들어요 |
| 화면마다 **빈 상태, 로딩 중, 오류** 화면도 함께 | 예: 여행이 하나도 없을 때 무엇을 보여줄지 |
| Figma 파일에 **정욱 초대** | 디자인 값(색, 간격)을 직접 확인할 수 있어요 |

## 기술적 한계 (디자인 전에 알아 두면 좋은 것)
- **처음에는 앱스토어 앱이 아니라 "웹 앱(PWA)"으로 출시해요.** 스토어 등록비가 들어서, 우선 웹사이트를 폰 홈 화면에 앱처럼 설치해서 쓰는 방식이에요. 겉보기와 사용감은 앱과 거의 같아요.
- **홈 화면 위젯은 처음에는 못 만들어요.** 웹 앱에서는 위젯 기능 자체가 없어요. 나중에 정식 앱으로 출시할 때 만들 수 있어요. 대신 "앱을 열면 바로 오늘 화면"으로 최대한 빠르게 볼 수 있게 할게요.
- **지도는 무료 지도(OpenStreetMap)를 써요.** 구글맵은 사용량에 따라 비용이 나와요. 무료 지도는 구글맵보다 덜 화려할 수 있어서, 지도 위의 핀이나 동선 선 스타일을 디자인에서 신경 써 주면 좋아요.
- **아이폰은 "공유 → 홈 화면에 추가"를 사용자가 직접 해야 설치돼요.** 첫 화면에 설치 방법을 안내하는 디자인이 필요할 수 있어요.

## 기획 질문 (답해 주세요 🙏)
1. **"확정(픽스)"한 일정은 수정이 아예 안 되어야 할까요, 아니면 수정은 되는데 "확정됨" 표시만 있으면 될까요?**
2. 일정을 확정하는 건 **누구**가 할 수 있어야 할까요? (만든 사람만? 아무나?)
3. 정산할 때 **나라 통화와 원화**를 섞어 쓰는 경우가 많나요? (예: 숙소는 원화로 미리 결제, 현지 식비는 엔화)
4. 나라 추천 질문으로 무엇을 물어보면 좋을까요? (지금 생각: 휴양 vs 도시, 예산, 비행시간, 음식, 날씨)
5. "오늘 화면"에 꼭 보여야 하는 정보는? (지금 생각: 오늘 장소 순서, 지도 동선, 다음 장소까지 시간)
